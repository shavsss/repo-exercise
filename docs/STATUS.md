- **המקרה ההנדסי, תת-שלב 2 (17.11): חדר העבודה** (לנצ'סטר וגילואה, קבצים זהים):
  - כרטיס בשיעור (`CaseCard` ב-`components/CaseRoom.tsx`, במקום `CasePreview`): מספר מסמך, כותרת, פס סעיפים עם מצב, התקדמות וכפתור "פתח את חדר העבודה". גובה קבוע (13.75rem), כך שפעולה לא משנה את גובה הטקסט בספר.
  - חדר מסך מלא מחוץ לספר (`CaseRoomHost` ב-App, portal, אירוע `case:open`): כותרת מסמך תכן (DD-…, טיוטה ← בסקירה ← אושר, בעלים, סוקרים), סעיפים בצד (פתוח / בסקירה / סגור, נעולים עד שהקודם נסגר), ובכל סעיף: הצעה ונימוק עם ביטחון באחוזים (חובה) ← שרשור סקירה עם תגי תפקיד ו"סמן כנפתר" ← "חשב / דמה לי" כתא מחברת In/Out (סקריפט math.js רץ ישר; מילים עוברות למודל עם compute) ← "פתרתי ומתחייב" (החלטה בשורה וביטחון סופי) ← נימוק מומחה ומחוון עם הפריט המכריע מודגש (אפשר לערער על סימון) ← "מה המומחה ראה שאני לא" (חובה) ← הסעיף הבא. בצד השני: יומן החלטות, ספר מספרים (תגי `<<מספר:…>>` של הסוקר ותוצאות תאים), הנחות פתוחות. בסוף: טופס ADR ← מסמך ADR-<מודול>-<NNN> ← תחקיר post-mortem. "שמור רעיון" מכל מקום ולוח מחסן הרעיונות (זרע ← מבשיל ← פרויקט).
  - מודלים: Opus 5.5 לכל התורות (medium לסקירה ולחישוב, high לנימוק ולתחקיר), נפילה ל-Sonnet 5.5. ההוראות ב-`src/casePrompt.ts`.
  - קוד משותף: `src/sampleRun.ts` (`sampleWithFallback`, `computeTool`) משמש גם את `Consult.tsx`.
  - אחסון: `src/caseDoc.ts` (טיפוסים ולוגיקה טהורה: דירוג מחוון, ביטחון ← Conf, `fitCase` מתחת ל-200KB), `src/caseStore.ts` (היקף השיעור הפתוח, שמירה מושהית ועותק ב-localStorage), `Store.loadCase/saveCase` (`profile/cases/<module>__<lesson>`). אירוע `case.commit` (שלב, ביטחון) ורשומת כיול לכל שלב (`kind: "case"`, id `<module>__<lesson>__case-<stage>`).

- **המקרה ההנדסי, תת-שלב 1 (17.11): כללים ויצירת השיעור** (לנצ'סטר וגילואה, `docs/ENGINEERING_CASE.md`):

  - יצירה: המתכנן שומר `case` ב-"blocks" של החלק האחרון ובשדה `case` של התוכנית (`CASE_PLAN`); החלק האחרון כותב keep ← משפט על השיעור הבא ← בלוק case אחד (`CASE_PART`, ב-`bookRules.ts`). הפורמט והבדיקה ב-`src/caseBlock.ts` (חדש, זהה בשתיהן). ה-LessonFeature `decide` הוחלף ב-`case`; `decideSlot`/`decideLine`/DECIDE_PART נמחקו. הרכיבים Decide ו-ErrorHunt נשארו לשיעורים שמורים.
