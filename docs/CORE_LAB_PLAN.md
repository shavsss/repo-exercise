# מעבדת הליבה: החלטות תכנון

ההחלטות נאספו בדף התכנון (https://claude.ai/artifact/DvDyz9pF1AmrC2WfTTWJ9G) ונסגרו בשיחה.

| נושא | החלטה |
|---|---|
| מפת המודולים | רשימה לפי 13 החלקים, עם מצב לכל מודול (נלמד, זמין, נעול). לחיצה על מודול נעול מראה מה חסר. |
| מעבר בין מודולים | מותר לקפוץ רק למודול שכל הדרישות המוקדמות שלו נלמדו. |
| מתי מודול נלמד | אוטומטית, כשכל השיעורים שלו הסתיימו. |
| מסך השיעור | צ'אט כמו במעבדת הלמידה: שיעור לפי כללי הלימוד, עם שאלות ודיון. צופה המקורות נפתח כחלון צד רק בלחיצה על תגית עמוד. |
| הפניה למקורות | תגית עמוד בלבד (למשל "POMR עמ' 115"). לחיצה פותחת את העמוד בצופה. |
| איורים | האיור המקורי חתוך וגדול בתוך השיעור; לחיצה פותחת את העמוד המלא. |
| סימולטורים | 15–20 סימולטורים מוכנים ובדוקים, ובנוסף אנימציה שהמורה כותב לנושאים אחרים, מסומנת ככזו. |
| תמונות של מערכות | תמונות חופשיות מ-Wikimedia, אם הדף מורשה להציג אותן. |
| יחידת השיעור | המורה מחלק כל מודול לשיעורים לפי הסעיפים. החלוקה חייבת לכסות כל סעיף בעמודי המודול, לבדוק חפיפות בין המקורות, ולוודא בסוף שלא הושמט דבר. |
| אורך שיעור | ליבה ומתקדם: לפחות 4000 מילים. כשהסעיף עצמו קצר, מותר פחות, והמורה אומר במפורש שזה כי אין מה להוסיף. עיון: קצר יותר. |
| מערכות בשטח | רק כשיש קשר אמיתי. כולל גם איך מדינות בונות ומשתמשות, וכיוונים תעשייתיים: רוסיה, ארה"ב, סין, טורקיה, ישראל, דרום קוריאה והתעשיות האירופיות. |
| כללי הלימוד | ארבעת השינויים אושרו: "מוצרים" הופך ל"מערכות בשטח"; מקרה בוחן הוא אירוע מבצעי; "4 תחומים" הופך לחיבור לתחומי הליבה; תרגילים הם חישובי מהנדס והערכות אנליסט. |
| תרגול | תרגילים בכל שיעור (לפי כללי הלימוד) ומבחן מסכם לכל מודול. בלי חזרה מרווחת. |
| סגנון חזותי | שרטוט הנדסי, בגרסה בהירה וכהה לפי הגדרות המערכת. הפרטים נבחרים בסבב שני בדף הסגנון (https://claude.ai/artifact/Uzwxw4BG2E4xrEvjMcwaEV). |

## כלל קבע: מערכות בשטח

הכלל הזה ייכנס לכללי הלימוד של מעבדת הליבה (בהנחיות המורה ובמסמך הכללים), ולא יהיה תלוי בשיקול דעת מקרי.

- בכל שיעור שבו העיקרון הנלמד מופיע במערכות אמיתיות, המורה בודק כדבר שבשגרה את המערכות, את אופן ההפעלה ואת כיווני התעשייה במדינות המרכזיות: רוסיה, ארה"ב, סין, טורקיה, ישראל, דרום קוריאה והתעשיות האירופיות.
- הבדיקה כוללת מקורות בשפות המקור (רוסית, סינית, עברית, טורקית, קוריאנית ושפות אירופיות): שם המערכת והמונחים בשפת המקור, ומה ידוע מהספרות המקצועית, התעשייתית והרשמית באותה שפה.
- לכל טענה: רמת ודאות, סוג המקור (רשמי, תעשייתי, מחקרי, תקשורתי, OSINT), ומתי הידע עדכני.
- מגבלה: למורה שרץ בתוך ה-Artifact אין חיפוש באינטרנט. הבדיקה נשענת על הידע שלו, כולל ספרות בשפות המקור, ולכן הוא מציין מתי הידע עלול להיות לא עדכני. מקור שהלומד מדביק בשיחה גובר על הידע שלו.
