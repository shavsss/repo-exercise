# סבב 8: סדר לימוד בשכבות (15.11)

הצעה, עוד לא מיושמת באפליקציות. המפה: https://claude.ai/artifact/YFyaqvM7thdd6hvG8DPvYs (`learning-map.html`).

- `eng_plan.py`, `mil_plan.py`: השכבות של גילואה, בלוקי לנצ'סטר, המודולים החדשים (הצעות הלומד, פערים, הנדסה ימית) ודרישות קדם שחסרו באינדקס.
- `check_layers.py eng eng_plan.py`: בודק שכל מודול בא אחרי דרישות הקדם שלו (0 שגיאות). `sync.py`: מאיזו שכבה בגילואה כל בלוק בלנצ'סטר יכול להתחיל, וזמן משוער.
- `eng_gaps.md`, `mil_gaps.md`: בדיקות הפערים (מקורות, עמודים, טעויות סדר). הערה: "עשרה מודולים בלי מקור" ב-mil_gaps שגוי, הם נלמדים ממאמרים.
- הסקריפטים קוראים את `tmp/syllabus/*_modules.txt`, שנבנים מה-`lib/index.json` המפורסם (ראה build_map.py).
- `eng_items.json`, `mil_items.json`: תתי-הנושאים של כל מודול חדש (K/S/C, חסר או העמקה, ואיפה זה כבר נלמד), בפורמט ה-items של curriculum.json. `item_cost.py` מתמחר אותם לפי add_item_estimates של סבב 3: 846 תתי-נושאים, כ-564 שעות (כ-3.7 חודשים). הערכה ראשונה בעמודים (כ-15 חודשים) הייתה שגויה: לומדים לפי תתי-נושאים, לא קוראים ספרים.
