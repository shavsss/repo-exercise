# סבב 5, רצועת UX: מקום לשעות ארוכות (30.10.2026)

מחקר על נוחות והנאה ביום לימוד של 8–10 שעות בשתי המעבדות. לא שונה קוד באפליקציות.

- הדוח: https://claude.ai/artifact/DDrugZAMN4BnnLEXWfJypn (`report.html`)
- לוח הבחירות (17 החלטות, נשמר באוסף `ux5_choices`): https://claude.ai/artifact/1mddveQUYTeWBR2tyBxHEp (`board.html`; אבות-הטיפוס מתפרסמים איתו תחת `proto/`)

## המסמכים
- `F1_visual_fatigue.md`: עייפות ראייה, טיפוגרפיה עברית, ניגודיות, אור כחול, תנועה.
- `F2_cognitive_session.md`: עייפות קוגניטיבית וגופנית, הפסקות, מבנה היום, כללי אנטי-נדנוד (N1–N8), מנגנונים M1–M13.
- `F3_sound.md`: צליל לשעות ארוכות, מפרט v2 (הקלדה, צלילים, חדר ספרייה גנרטיבי).
- `F4_enjoyment.md`: הנאה וזרימה, פירוק כלים, דפוסים להימנע מהם, שלושה רגעים חתומים.
- `F5_app_audit.md`: ביקורת קוד של הנוחות, ותדריך לפתקים בשוליים.
- `R1_redteam.md`: בדיקת מקורות ויישוב סתירות.
- `R2_lived_sim.md`: סימולציה של יום ושל 90 יום, ביקורת על אבות-הטיפוס.
