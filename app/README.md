# מעבדת הלמידה · Study Lab

אפליקציית צ'אט אישית ללימוד הספרים שבמאגר, סעיף אחר סעיף, עם Claude Opus 5.5. המורה כפוף לכל כללי הלימוד שלך: פתיחה בסיפור, חוט אחד, גזירות מלאות, שאלות עצירה, מקרה בוחן, ארבעה תחומים, רקע לכל מודל, תרגילים, וכל מספר מחושב בקוד. הכללים נמצאים במלואם ב-[`server/prompt.ts`](server/prompt.ts), ואפשר לערוך אותם שם.

## הפעלה

דרוש Node.js 20 ומעלה.

```bash
cd app
npm install
cp .env.example .env        # ולהכניס ANTHROPIC_API_KEY=...
npm run dev                 # http://localhost:5173
```

הפעלה בלי מצב פיתוח (שרת אחד):

```bash
npm run build && npm start  # http://localhost:5174
```

**בלי מפתח API** האפליקציה עולה ב**מצב הדגמה**: כל הודעה מקבלת שיעור מוכן מראש (על עמ' 240–241, האינווריאנטים של עקומים ממעלה שנייה) שמציג את כל רכיבי התצוגה. המספרים בשיעור ההדגמה חושבו בקוד שרץ באמת, והוא כולל גם טעות אמיתית שנמצאה בספר: בעמ' 241 כתוב 0.57 במקום 0.58.

## מה יש באפליקציה

- **המדף:** ששת הספרים כ"מחסניות" צבעוניות, עם העמוד הנוכחי בכל ספר (לחיצה על העמוד מאפשרת לעדכן אותו). הכפתור 📖 פותח צופה בטקסט וב-PDF של הספר.
- **שלושה סוגי הודעה:** *שיעור על סעיף* (המבנה המלא, 4000 מילים ומעלה), *שאלת הבהרה* (עומק מלא בלי פיגומים) ו*חופשי*. אפשר לבחור גם את עומק החשיבה של המודל, ולצרף צילום של עמוד.
- **המורה קורא את הספר בעצמו:** יש לו כלים לקריאת עמודים, לחיפוש בספר ולשמירת ההתקדמות. בנוסף יש לו הרצת קוד Python (כל מספר, גרף וטבלה מחושבים שם) וחיפוש ברשת לרקע היסטורי ולמקורות.
- **תצוגה עשירה:** בלוקים צבעוניים לסיפור, רקע, נוסחת מפתח, רענון כלי, תחום נוסף, מקרה בוחן, בניית מודל, טעות בספר ומוצר. שאלות "עצרו וחשבו" ותרגילים מגיעים עם רמז ופתרון מוסתרים ועם סימון "פתרתי". יש גם תגיות ודאות ומקור, תרשימים, שחזורי איורים, וכלים אינטראקטיביים עם מחוונים, כולל ציור עקומים מובלעים כמו חתכי חרוט.
- **גרפים שלא יכולים לשקר:** הקוד של המורה מדפיס את נתוני הגרף (`@@chart:...`), והאפליקציה מציירת את הגרף ישירות מהפלט. כל גרף מסומן אם הנתונים הגיעו מקוד.
- **בדיקת רף אוטומטית** בסוף כל שיעור: מספר מילים, סיפור, שאלות עצירה, רקע, מקרה בוחן, 4 תחומים, גרפיקה, הרצת קוד ותרגילים. כפתור "השלם את מה שחסר" מבקש מהמורה להשלים.
- **מפת תשובה** עם קפיצה לחלקים, פס התקדמות קריאה, מצב בהיר וכהה, ותמיכה בנייד.

## פרטים טכניים

- שרת Express (`server/`) מול ה-API של Anthropic. המודל: `claude-opus-5-5` עם adaptive thinking ותקציר מחשבות מוצג, וכל התשובות מוזרמות (streaming).
- נוסף **fallback בצד השרת** (`fallbacks: "default"`): אם מנגנון הבטיחות של המודל עוצר תשובה, ה-API מריץ אותה מחדש על מודל חלופי באותה קריאה. ממשק המשתמש מציין כשזה קורה.
- שיחות ארוכות מסוכמות אוטומטית בצד השרת (compaction) כשההקשר מתמלא. הנחיות המערכת והכלים נשמרים במטמון (prompt caching).
- הטקסט של הספרים חולץ מראש ל-`data/books/*.json`. אם מוסיפים ספר: מעדכנים את `data/catalog.json` ומריצים `npm run extract` (דורש `pdftotext`).
- השיחות וההתקדמות נשמרות ב-`data/user/`, שאינה נכנסת ל-git.

**עלות משוערת**: לפי המחיר של Opus 5.5 ($4 למיליון טוקנים בקלט, $20 בפלט), שיעור מלא עם קריאת עמודים, הרצות קוד וחשיבה צפוי לעלות בערך $0.5–2. העלות בפועל תלויה באורך הסעיף ובעומק החשיבה שנבחר, ומספר הטוקנים מוצג בתחתית כל תשובה.
