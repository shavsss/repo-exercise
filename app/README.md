# מעבדת הלמידה · Study Lab

**האפליקציה:** https://claude.ai/artifact/GQEfh2pKMGTUE5ARKh5rPb

מורה פרטי שמלמד את הספרים שבמאגר סעיף אחר סעיף. הדף רץ כ-Artifact ב-claude.ai, ולכן אין שרת ואין מפתח API. הוא פונה ל-Claude דרך `claude.use("sample")`, על החשבון של מי שצופה בו, ומבקש את Claude Opus 5.5. כל כללי הלימוד שלך נמצאים ב-[`src/prompt.ts`](src/prompt.ts).

## איך זה עובד

- **הספרים:** הטקסט של ששת הספרים מתפרסם יחד עם ה-Artifact הפרטי (`artifact/books/*.json`) ונטען אוטומטית. אפשר גם לטעון קובץ מהמחשב (כפתור ⬆), והוא יחליף את הגרסה המובנית בדפדפן הזה.
- **הנתונים שלך:** השיחות וההתקדמות נשמרים במסד הנתונים של ה-Artifact (`db`), בתיקייה הפרטית `data/users/<id>/`, שרק אתה רואה:
  - `data/users/<id>/profile`: העמוד הנוכחי בכל ספר והסעיף האחרון.
  - `data/users/<id>/profile/convs/<cid>`: פרטי השיחה.
  - `data/users/<id>/profile/convs/<cid>/msgs/<mid>`: ההודעות עצמן.
- **כלים של המורה:** קריאת עמודים, חיפוש בספר, חישוב (math.js) ושמירת התקדמות. העמודים שסביב המיקום שלך נשלחים כבר עם הבקשה. גרפים וטבלאות מוגדרים בביטויים מתמטיים, והדף מחשב אותם בעצמו, כך שאף ערך בהם לא מוקלד ביד.

## פיתוח

```bash
cd app
npm install
npm run build        # dist/app.js + dist/app.css
```

הדף שמתפרסם הוא `artifact/index.html`, עם `dist/app.js` ו-`dist/app.css` כקבצים נלווים. ההרשאות שהוא מצהיר עליהן: `sample` (כולל תמונות), `db` ו-`user`.

## מה ההבדל מגרסת השרת הקודמת

אין גישה לרשת, ולכן אין חיפוש ברשת: את הרקע ההיסטורי המורה כותב מהידע שלו, עם רמת ודאות לכל עובדה. החישובים רצים ב-math.js בדף במקום ב-Python. אורך הקלט לכל בקשה מוגבל (256KB), ולכן בשיחה ארוכה נשלחות רק ההודעות האחרונות. "השיעור הבא" פותח שיחה חדשה לכל סעיף, חוץ מסעיף שמחולק לכמה הודעות. תשובה שנקטעת באורך המרבי ממשיכה לבד, עד 4 חלקים, ומוצגת כהודעה אחת.
