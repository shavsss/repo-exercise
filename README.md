# repo-exercise

הספרים שאני לומד, ושתי אפליקציות הלמידה שנבנו סביבם.

| תיקייה | מה יש בה |
|---|---|
| [`library/`](library/README.md) | כל הספרים, המאמרים והדוקטרינה |
| `library/math-physics/` | מתמטיקה (כרכים 1–3) ופיינמן (כרכים I–III), והטקסט המחולץ שלהם (`text/`) |
| `library/military/` | הליבה הצבאית: ספרים, מאמרים, דוקטרינה |
| [`core/`](core/app/README.md) | לנצ'סטר: מעבדת הליבה הצבאית |
| [`eng/`](eng/app/README.md) | גילואה: מעבדת ההנדסה |
| `shared/` | קוד משותף לשתי המעבדות (תלת-ממד) |
| `docs/` | כללי הלימוד, הגיבוי ומדריך הבנייה |
| `notes/`, `backup/` | המחברת והגיבוי של מעבדת הלמידה הישנה (נתוני הלומד, נשמרים) |

מעבדת הלמידה (`app/`) נמחקה מהמאגר ב-17.11.2026, אחרי שהתמזגה לשתי המעבדות. ה-Artifact שלה (https://claude.ai/artifact/GQEfh2pKMGTUE5ARKh5rPb) לא נמחק ונשאר באוויר עד שהלומד ימחק אותו.
