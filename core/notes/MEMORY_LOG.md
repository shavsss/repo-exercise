- למה לוגריתמים: כפל→חיבור, דחיסת טווחים. מייל כבל תקני → decibel (Bell Labs, ודאות בינונית). נאפייר 1614, בריגס 1617.
- חזקות ולוגריתמים: $10^a\cdot10^b=10^{a+b}$ (1); $\log x=y\Leftrightarrow10^y=x$ (2); $\log(xy)=\log x+\log y$ (3); $\log(x/y)$ (4); $\log x^n=n\log x$ (5); $\log x^{1/n}$ (6). לוגריתם רק לחיוביים.
- $10\log(P/P_0)$ (8); $N(\text{dB})=10\log N$ (9), $N=10^{N/10}$ (10). 0 dB = פי 1.
- $P(\text{dBm})=10\log(P/1\,\text{mW})$ (11); $P(\text{dBm})=P(\text{dBW})+30$ (12). טבלה 2.1: dBm, dBW, dBsm, dBi. הגבר = out/in, אובדן = in/out.
- $z=y^a\Rightarrow z(\text{dB})=a\cdot y(\text{dB})$ (13). 1 dB≈1¼, 3 dB≈2, 7 dB≈5.
- $P_{tot}=10\log(10^{P_1/10}+10^{P_2/10})$ (14); 30⊕30 dBm = 33.01.
- תבניות (15) $A(\text{dBm})\pm B(\text{dB})$; (16) $A(\text{dBm})-B(\text{dBm})=C(\text{dB})$; (17). לכל היותר איבר מוחלט אחד בכל אגף.
- $L_s=32.44+20\log d_{km}+20\log f_{MHz}$ (18). הכפלת מרחק: +6.02 dB חד-כיווני, +12.04 במכ"ם.
