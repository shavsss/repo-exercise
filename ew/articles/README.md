# מאמרים לליבה הצבאית

המאמרים שמשלימים את הספרים, לפי סדר הלימוד. המספר בתחילת שם הקובץ הוא מספר הספר ומספר המאמר בטבלה המסכמת.

כל הקבצים כאן ציבוריים: arXiv, מאגרים אוניברסיטאיים, פטנטים, ומסמכי DTIC ו-NPS (רובם דרך המראה ב-archive.org).

## חסרים (הלומד מעלה)

01.1, 02.4, 02.5, 02.6, 03.2, 04.3, 04.4, 05.2, 05.4, 09.1, 11.9, 12.1. האתרים שלהם חוסמים הורדה מכאן.

## הערות

- `08.5` הוא בפועל *Extending the Wireshark Network Protocol Analyser to Decode Link 16 Tactical Data Link Messages* (DSTO-TN-1257), ו-`08.6` הוא *Open Source Analyzer for SISO-J Tactical Data Link Simulation*. אלה הכותרות שבקבצים עצמם.
- `07.2` הוא התקציר והממצאים של דוח APS (19 עמ'), לא הדוח המלא.
- `01.5b`, `08.1` ו-`11.11` סרוקים בלי שכבת טקסט, וצריך לעשות להם OCR לפני שהמורה יוכל לקרוא אותם.
