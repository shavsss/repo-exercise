# ספריית ההנדסה

הספרים של אפליקציית ההנדסה (בתכנון). הבסיס הוא ספרי המתמטיקה והפיזיקה ב-`library/math-physics/` (קולמוגורוב ופיינמן). סביבו בנויים חמישה צמתים שלומדים לעומק, ואחריהם גשרים ופריפריה. היעד הוא רמה 2.5: מבנה, מקור, גבולות, סדרי גודל, פשרות, מבנים משותפים וביקורת.

**מי מביא:** "Claude" מסמן ספר חינמי שהמחבר או המוסד פרסמו, וכבר הורד. "הלומד" מסמן ספר שצריך להעלות לתיקייה `books/` בשם שבטבלה.

- מחשוב קוונטי: פיינמן III נותן את הבסיס.
- ייצור, ביו-רפואה, הנדסה אזרחית.
