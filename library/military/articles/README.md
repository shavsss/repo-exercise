# מאמרים לליבה הצבאית

המאמרים שמשלימים את הספרים, לפי סדר הלימוד. המספר בתחילת שם הקובץ הוא מספר הספר ומספר המאמר בטבלה המסכמת.

כל הקבצים כאן ציבוריים: arXiv, מאגרים אוניברסיטאיים, פטנטים, ומסמכי DTIC ו-NPS (רובם דרך המראה ב-archive.org).
